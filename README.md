# AVCheck2

一个用于离线整理 Windows 进程列表的轻量脚本。它将进程名与本地维护的安全软件进程映射表进行比对，并输出可能识别到的安全产品名称。

本仓库是对 [AVCheck](https://github.com/wwl012345/AVCheck) 的个人维护与学习分支，主要关注代码健壮性、数据读取和结果去重等基础工程问题。

## 工作方式

```text
进程列表文本
        ↓
提取每行的进程名
        ↓
与 杀软识别.txt 中的映射表比对
        ↓
输出去重后的识别结果
```

它不会扫描文件、修改系统设置或执行规避操作；输入与输出均为本地文本处理。

## 环境

- Python 3.9+
- 无第三方 Python 依赖

创建本地环境：

```powershell
python -m venv .venv
```

## 使用方式

准备一份由你本人设备或已获授权环境导出的进程列表文本，然后运行：

```powershell
.\.venv\Scripts\python.exe AVCheck.py -f <进程列表文件>
```

`杀软识别.txt` 保存进程名与产品名称的映射数据。结果仅供资产盘点、实验环境确认或安全运维学习参考，不能代替专业安全产品或正式审计结论。

## 隐私与使用边界

进程列表可能暴露设备上安装的软件、远程管理工具或运行环境。请勿提交、上传或公开真实生产设备导出的进程清单；发布示例时应使用脱敏或虚构数据。
